# Gregor Opmann – IT Portfolio

A high-performance, responsive portfolio website built with a focus on hardware optimization and clean UI.

## 🚀 Features
* **Glassmorphism UI:** Modern frosted-glass aesthetic using `backdrop-filter`.
* **Bilingual Support:** Full toggle between Estonian and English.
* **Dynamic Theme Switcher:** Light/Dark mode with system persistence.
* **Performance Optimized:** Lazy-loaded images and intersection observers for smooth scroll animations.
* **Hardware Focused:** Integrated specs table and project gallery.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6)
* **Tools:** VS Code, GitHub Pages, Google Analytics
* **Hardware Experience:** Python (ProgeStart 2025), Arduino, Raspberry Pi
